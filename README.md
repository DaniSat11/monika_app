# Monika AI Companion (Flutter)

Интерактивный мобильный компаньон в стиле культовой визуальной новеллы *Doki Doki Literature Club!*, работающий на базе искусственного интеллекта (DeepSeek API).

## 💡 О проекте
Это приложение позволяет общаться с цифровой Моникой прямо на телефоне. Персонаж динамически меняет выражения лица (эмоции) в зависимости от контекста диалога, поддерживая атмосферу оригинальной игры.

## 🛠 Технологии
- **Фреймворк:** Flutter (Dart)
- **Интеграция:** DeepSeek API
- **Хранение данных:** SharedPreferences

## ✨ Особенности
- Атмосферный интерфейс в стиле DDLC.
- Система эмоциональных спрайтов (реакция на реплики через текстовые теги).
- Поддержка донатов (раздел авторов/благодарностей).
